## Overview

Project information was spread across documents, messages and spreadsheets. This platform brings task status, ownership, risks, dependencies and supporting files together so everyone can see where a project stands.

## What I built

- **Application.** Built on a cloud-hosted environment, with SQL for structured data and Google Drive integration for project documents.
- **API and workflow integration.** Connected project documents and data sources through APIs, so information and workflow updates are easy to reach.
- **Agile project tracking.** Developed in agile-style iterations, covering tasks, progress, ownership, risks and dependencies.
- **Business analysis.** Turned user needs into tracking requirements, data fields and workflow steps.

## Impact

A completed platform that improved project visibility and coordination, and gave me hands-on experience with SQL-backed applications, cloud deployment and API-based workflows.
