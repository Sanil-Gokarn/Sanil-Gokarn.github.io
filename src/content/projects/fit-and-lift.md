## Overview

Fit and Lift is a web app for tracking everything that matters in a training plan: calories, exercises, weights lifted, progress and goals, with dashboards that show how it all trends over time.

## What I built

- **AI-enabled development.** Built the app with Claude and MCP server concepts, improving it in agile-style iterations based on user needs.
- **Data capture and storage.** Designed a SQL schema for calorie intake, exercises, lifted weight, progress, goals, bulking or cutting preference, and workout history.
- **Dashboards.** Views for calories, exercise progress, lifted weight and goal alignment, so users can see their patterns over time.
- **Responsive design.** Works on both laptop and mobile.

## Impact

A working application with real users, showing hands-on experience with AI-enabled workflows, SQL-backed tracking and dashboard-based personal analytics.
